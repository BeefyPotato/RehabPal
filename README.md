# RehabPal
RehabPal is a Vision Pro app that makes hand and finger physiotherapy more engaging through spatial games, adaptive tracking, progress insights, and habit-building features.

## Run in Xcode

1. Open `RehabPal.xcodeproj` in Xcode 27 or later.
2. Select the `RehabPal` scheme.
3. Choose an Apple Vision Pro simulator or connected device.
4. Run the app.
