# RehabPal
RehabPal is a Vision Pro app that makes hand and finger physiotherapy more engaging through spatial games, adaptive tracking, progress insights, and habit-building features.

## Run in Xcode

1. Open `RehabPal.xcodeproj` in Xcode 27 or later.
2. Select the `RehabPal` scheme.
3. Choose an Apple Vision Pro simulator or connected device.
4. Run the app.

## Demo

The one-shot prototype is implemented on the `one-shot-prototype` branch. It runs entirely in memory and includes the medication gate, two prescribed spatial exercises, daily fixed assessment, symptom check, after-care report, and Recovery Pet reward.

See [`docs/demo-walkthrough.md`](docs/demo-walkthrough.md) for the repeatable simulator fallback and Vision Pro device walkthroughs. Placeholder model licensing and conversion details are recorded in [`ASSET_ATTRIBUTION.md`](ASSET_ATTRIBUTION.md).
